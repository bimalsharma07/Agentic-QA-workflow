# Agentic QA Workflow – Playwright + MCP + GitHub MCP

This repository showcases a fully agentic, AI‑driven QA automation workflow where Playwright tests are generated, healed, updated, and committed automatically using MCP‑powered agents. All tests target **https://www.saucedemo.com/** and are created without manual coding.

Repository:  
https://github.com/bimalsharma07/Agentic-QA-workflow/tree/main

---

## 🚀 Overview

This project demonstrates how modern agentic systems can autonomously:

- Plan test coverage  
- Generate Playwright tests  
- Heal broken selectors  
- Re‑generate failing tests  
- Commit and push updates to GitHub  

The entire workflow is powered by **Playwright MCP**, **Playwright Agents**, and **GitHub MCP**, forming a self‑maintaining automation pipeline.

---

## 🧠 Agentic Components

### 1. Playwright
Playwright provides the browser automation foundation.  
All tests (`*.spec.ts`) are standard Playwright tests generated by AI.

---

### 2. Playwright MCP
Playwright MCP introduces autonomous agents that manage the full lifecycle of test creation:

#### Planner Agent
- Determines what test scenarios should exist  
- Understands user flows (login, cart, checkout, etc.)  
- Creates a structured test plan

#### Generator Agent
- Writes Playwright test code automatically  
- Generates page objects and reusable utilities  
- Ensures tests follow best practices

#### Healer Agent
- Detects failing tests caused by UI changes  
- Repairs selectors and regenerates broken tests  
- Keeps the suite stable without human intervention

---

### 3. Playwright Agents
These agents combine reasoning with browser automation:

- Inspect DOM semantically  
- Adapt to UI changes  
- Maintain low‑flakiness tests  
- Continuously improve test quality

---

### 4. GitHub MCP
GitHub MCP handles repository operations:

- Creates branches  
- Commits regenerated tests  
- Pushes updates automatically  
- Opens pull requests when needed  

This enables a hands‑off CI workflow where AI maintains the repo.
