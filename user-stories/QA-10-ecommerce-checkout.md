# QA-10: Ecommerce Checkout Workflow

## Summary
As a user, I want to purchase one or more products from the SauceDemo storefront so that I can complete a checkout successfully and receive confirmation.

## Acceptance Criteria
1. A user can log in with valid credentials and access the inventory page.
2. A user can add products to the cart and navigate to the cart page.
3. A user can proceed to checkout and enter valid personal information.
4. A user can complete the order and see a confirmation page.
5. The system shows validation errors when required checkout fields are empty or invalid.
6. The cart total and item count are reflected correctly throughout the purchase flow.
